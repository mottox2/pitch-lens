# PitchLens

PitchLens は、マイクから取り込んだ音の音程をリアルタイムに確認できる macOS アプリです。音名やセントのずれ、音程の履歴を表示します。

## ダウンロード

現在、初回リリースを準備中です。公開後は [最新リリース](https://github.com/mottox2/pitch-lens/releases/latest) から Apple Silicon Mac 用の DMG をダウンロードし、PitchLens を「アプリケーション」フォルダにコピーしてください。

macOS 13 以降の Apple Silicon Mac に対応しています。

## 使い方

ツールバーのマイクボタン、または **Cmd+Shift+M** で音程の検出を開始・停止できます。初回はマイクの使用を許可してください。

ウィンドウを閉じてもアプリは常駐します。終了するには、設定メニューの「PitchLensを終了」または **Cmd+Q** を使ってください。

音声は保存・送信しません。音程の履歴はアプリの終了時に消去されます。
